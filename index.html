Dataset Information

Data Sources

  • SSURGO: USDA NRCS Soil Survey Geographic Database
  • Soil Properties: SoilGrids 250m Resolution (ISRIC)
  • Soil Orders: USDA Soil Taxonomy Classification
  • Temperature: WorldClim 2.1 Bioclimatic Variables
  • Land Cover: NLCD 2024 (30m)
  • Lithology: USGS State Geologic Map
  • Elevation: USGS 3D Elevation Program (10m DEM)
  • Satellite: Esri World Imagery Service
